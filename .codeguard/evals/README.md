# CodeGuard Evaluations

This folder contains benchmark tasks and evaluation cases used to measure agent quality.

Goals:
- Detect regressions in prompt quality
- Compare prompt versions
- Compare model performance
- Measure token efficiency
- Validate guardrails
- Measure false positives and missed issues

Future evaluations may include:
- Security fixes
- Refactoring tasks
- PR reviews
- Test generation
- Compile failure recovery
- Large diff handling
